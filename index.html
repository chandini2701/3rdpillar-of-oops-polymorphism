01 / INTRODUCTION

What is Polymorphism?

Polymorphism is one of the four main pillars of Object-Oriented Programming (OOP) in Java. The word polymorphism comes from two words:

Poly

Means many.

Morphism

Means forms.

Definition: Polymorphism is the ability of an object or method to take many forms and behave differently depending on the situation.

Real-life example

A person can act as a student in college, an employee at work, and a customer in a shop. The same person performs different roles in different situations.

Similarly, in Java, the same method name or parent reference can produce different behavior.

02 / CLASSIFICATION

Types of Polymorphism

01

Compile-Time Polymorphism

Achieved through method overloading. The compiler selects the appropriate method based on its arguments.

Also called: Static polymorphism.

02

Runtime Polymorphism

Achieved through method overriding. The actual object's implementation is selected at runtime.

Also called: Dynamic polymorphism.

Difference between the two

Feature Compile-Time Runtime
Technique Overloading Overriding
Selection By compiler By runtime object type
Inheritance required? No Yes, typically
Parameters Must differ Must match for overriding
Binding Generally static Dynamic method dispatch

03 / JAVA PROGRAMS

Example 1: Method Overloading

Method overloading means creating multiple methods with the same name but different parameter lists in the same class.

Calculator.java
class Calculator {

    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    double add(double a, double b) {
        return a + b;
    }

    public static void main(String[] args) {
        Calculator c = new Calculator();

        System.out.println(c.add(10, 20));
        System.out.println(c.add(10, 20, 30));
        System.out.println(c.add(2.5, 3.5));
    }
}

Output

30
60
6.0

Explanation:

  • add(10, 20) calls the two-integer method.
  • add(10, 20, 30) calls the three-integer method.
  • add(2.5, 3.5) calls the two-double method.

All three methods have the same name, but their parameter lists differ. The compiler determines which method to call.

Example 2: Method Overriding

Method overriding happens when a child class provides its own implementation of an inherited instance method.

Animal.java
class Animal {

    void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

class Cat extends Animal {

    @Override
    void sound() {
        System.out.println("Cat meows");
    }
}

public class Main {

    public static void main(String[] args) {
        Animal a;

        a = new Dog();
        a.sound();

        a = new Cat();
        a.sound();
    }
}

Output

Dog barks
Cat meows

Explanation:

  • Animal a; declares a parent-class reference.
  • a = new Dog(); makes it refer to a Dog object.
  • a.sound(); executes the Dog implementation.
  • a = new Cat(); makes it refer to a Cat object.
  • The next a.sound(); executes the Cat implementation.
Important: In runtime polymorphism, the overridden instance method is selected according to the actual object's class, not merely the reference variable's declared type.

04 / RULES

Important Rules of Polymorphism

  • Overloaded methods must have different parameter lists.
  • Changing only the return type does not create a valid overload.
  • An overridden method must have a compatible return type.
  • An overriding method cannot reduce access visibility.
  • Use @Override to help the compiler check overriding.
  • Static methods are hidden, not overridden in the runtime-dispatch sense.
  • Private methods are not inherited and overridden in the usual sense.
  • Constructors cannot be overridden.
  • Final methods cannot be overridden.

05 / BENEFITS

Advantages of Polymorphism

Code Reusability

Common interfaces can be used for different implementations.

Flexibility

The same method call can produce different behavior.

Maintainability

New implementations can be added with fewer changes to calling code.

Loose Coupling

Code can depend on a parent class or interface instead of a specific implementation.

07 / QUICK REVISION

Interview Questions

1. What is polymorphism in Java?

It is the ability to represent different behaviors through the same method name or common parent type.

2. What are the two main types?

Compile-time polymorphism and runtime polymorphism.

3. What is method overloading?

Defining methods with the same name but different parameter lists.

4. What is method overriding?

A subclass provides a compatible implementation of an inherited instance method.

5. Can we overload the main method?

Yes. However, the Java launcher starts the program using the recognized main entry-point signature.

6. Can we override a final method?

No. A final method cannot be overridden by a subclass.

7. Is polymorphism an OOP pillar?

Yes. The four commonly taught OOP pillars are encapsulation, inheritance, abstraction, and polymorphism.
